# Forsaken

**Forsaken** is an atmospheric 2D top-down indie game built with **C++** and the **SFML** library. Dive into a mysterious, abandoned forest environment, interact with unique wildlife characters, complete quests, solve ecology tests, and clean up the wilderness!

---

## Features

* **Exploration & View:** Smooth camera following mechanics as you explore a vast woodland map.
* **Interactive Wildlife & NPCs:** Talk to animals (a wise deer keeper, a wolf, a hedgehog, a cat, and an antelope) featuring animated typewriter-style dialogue boxes.
* **Environmental Quest System:** Track your tasks dynamically and help restore the forest.
* **Trash Collection Mechanics:** Pick up scattered garbage items and throw them into designated waste holes.
* **Interactive Botany:** Discover and inspect rare plant species, unlocking informational pop-up windows.
* **Quiz System:** Test your knowledge at the end of your journey with an integrated interactive keeper quiz.
* **Immersive Audio & UI:** Complete with custom background forest ambient sound, main menu controls, custom fonts, and a full-screen dynamic interface.

---

## Tech Stack & Libraries

* **Language:** C++
* **Graphics & Audio:** SFML (Simple and Fast Multimedia Library) v2.6.0
* **Build System:** Visual Studio Solution (`.sln` / `.vcxproj`)

---

## Getting Started

### Prerequisites
Make sure you have a Windows environment with Visual Studio installed (or a compatible C++ compiler setup with SFML configured), along with the necessary runtime `.dll` files placed in your execution directory.

### Running the Project
1. Clone the repository to your local machine.
2. Open `Forsaken.sln` in Visual Studio.
3. Build and run the solution in **Debug** or **Release** (x64) mode.

## Controls

* **W, A, S, D** — Move the Fox character
* **E** — Interact with NPCs and objects
* **Space** — Skip messages / close dialog notifications
* **R** — Toggle task list visibility
* **Left Mouse Click** — Interact with menu buttons and dialogue options
